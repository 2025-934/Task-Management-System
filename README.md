# 🚀 Task Manager - College Mini Project

A modern, responsive, and feature-rich **Task Management System** web application built for college students. 

This project requires **no backend setup, installation commands, or database configuration**. It runs directly inside any web browser!

---

## ✨ Key Features

- **📊 Dynamic Dashboard:** Real-time summary cards tracking Total Tasks, Pending Tasks, Completed Tasks, and Overdue items.
- **✨ Full Task Lifecycle:** Add, Edit, Delete, Mark as Completed, or Reopen tasks seamlessly.
- **🔍 Search & Filter:** Instantly filter tasks by status (Pending/Completed), priority level (Low/Medium/High), or search by title.
- **💾 Local Storage Persistence:** All tasks are automatically saved to your browser, so your data stays safe even after refreshing the page.
- **🎨 Modern UI/UX:** Clean, professional purple-and-slate theme with rounded cards, smooth transitions, and mobile-friendly responsiveness.
- **🚀 Pre-loaded Sample Data:** Comes with sample tasks right out of the box so the dashboard looks vibrant immediately upon opening.

---

## 🛠️ Technologies Used

- **HTML5** (Semantic structure)
- **Tailwind CSS** (Modern utility-first styling & responsiveness)
- **JavaScript (ES6+)** (Dynamic interactivity, state management, and Local Storage API)
- **FontAwesome** (Clean icons)
